Funciones hash y distribución de claves

Comprender cómo las funciones hash transforman las claves en índices, los métodos básicos de cálculo, las propiedades de una buena función hash y la importancia del factor de carga.

Introducción

Las tablas hash permiten almacenar y recuperar información mediante claves que identifican los elementos. Para lograr un acceso eficiente, necesitan un mecanismo que determine dónde debe ubicarse cada registro dentro de la estructura de almacenamiento.

Este mecanismo se conoce como función hash (hash function) y constituye uno de los componentes fundamentales de las tablas hash. Su propósito consiste en procesar una clave y generar un valor numérico que pueda utilizarse para calcular una posición dentro de la tabla.

La eficiencia de una tabla hash depende, en gran medida, de la capacidad de su función hash para distribuir las claves entre las posiciones disponibles. Una distribución adecuada reduce la frecuencia de colisiones y favorece un acceso rápido a los elementos almacenados.

En Python, las funciones hash forman parte del funcionamiento interno de los diccionarios dict y los conjuntos set. También es posible implementar funciones propias para comprender cómo se calculan los índices y cómo se distribuyen las claves.

2.1 Concepto y propósito de una función hash

Una función hash es un procedimiento que transforma una clave de entrada en un valor numérico denominado valor hash. En una tabla hash, este valor se utiliza para determinar la posición donde debe almacenarse o buscarse un elemento.

Su propósito principal consiste en establecer una relación reproducible entre una clave y su ubicación dentro de la estructura.

Funcionamiento conceptual

Clave
25
→
Función hash
h(k)
→
Índice
5

La clave se transforma mediante una función para determinar una posición válida de almacenamiento.

Por ejemplo, si una tabla dispone de diez posiciones y se utiliza una función basada en el residuo de la división, la clave 25 puede asignarse a la posición 5.

Características fundamentales

Determinismo

Una misma clave produce el mismo resultado cuando se mantiene la misma función y configuración.

Transformación

Convierte claves en valores numéricos utilizables para calcular índices.

Reproducibilidad

Permite localizar nuevamente un elemento utilizando su clave.

Eficiencia

Debe calcularse sin introducir operaciones innecesariamente costosas.

Distribución

Procura repartir las claves entre las posiciones disponibles de la tabla.

Ejemplo en Python

def funcion_hash(clave, capacidad):
    return clave % capacidad

print(funcion_hash(25, 10))
print(funcion_hash(37, 10))
print(funcion_hash(48, 10))
Resultado: 
5
7
8

La operación % calcula el residuo de una división. Con una capacidad de diez posiciones, permite obtener índices comprendidos entre 0 y 9 para claves enteras.

2.2 Transformación de claves en índices

Una tabla hash almacena sus elementos en posiciones identificadas mediante índices numéricos. La forma de obtener estos índices depende del tipo de clave utilizada.

Transformación de claves numéricas

Para una tabla con diez posiciones puede utilizarse la siguiente función:

h(k) = k mod 10
  • h(k): índice calculado.
  • k: clave numérica.
  • 10: capacidad de la tabla.
  • mod: residuo de la división.
Clave Operación Índice
21 21 % 10 1
34 34 % 10 4
56 56 % 10 6
79 79 % 10 9 
capacidad = 10

claves = [21, 34, 56, 79]

for clave in claves:
    indice = clave % capacidad
    print(f"Clave: {clave} - Índice: {indice}")
Resultado: 
Clave: 21 - Índice: 1
Clave: 34 - Índice: 4
Clave: 56 - Índice: 6
Clave: 79 - Índice: 9

Transformación de claves textuales

Las claves también pueden ser cadenas de texto, como códigos de productos, nombres de usuarios e identificadores. Una técnica educativa consiste en convertir cada carácter a su valor numérico Unicode mediante la función ord() y sumar los resultados.

Carácter Valor Unicode
A 65
N 78
A 65
Total 208
h(ANA) = 208 mod 10 = 8
def hash_texto(clave, capacidad):
    suma = 0

    for caracter in clave:
        suma += ord(caracter)

    return suma % capacidad


print(hash_texto("ANA", 10))
print(hash_texto("LUIS", 10))
Resultado: 
8
7
Limitación del método

Las palabras formadas por los mismos caracteres, aunque estén en distinto orden, producen la misma suma. Por ejemplo, ANA y NAA generarían el mismo índice.

Uso de la función hash integrada de Python

Python proporciona la función hash(), que obtiene el valor hash de un objeto compatible.

clave = "PROD001"

valor_hash = hash(clave)

print("Valor hash:", valor_hash)

Importante: el valor devuelto por hash() para cadenas puede cambiar entre ejecuciones de Python debido a la aleatorización. Además, no debe confundirse con una función hash criptográfica diseñada para proteger contraseñas o verificar la integridad de la información.

2.3 Características de una buena función hash

Una función hash debe diseñarse considerando la cantidad de posiciones disponibles, el tipo de claves y las operaciones que realizará el sistema.

Una función deficiente puede provocar que numerosas claves terminen en las mismas posiciones, reduciendo la eficiencia de la tabla.

Determinismo

La misma clave debe producir el mismo resultado bajo iguales condiciones.

Distribución uniforme

Procura repartir las claves entre las posiciones disponibles.

Rapidez de cálculo

Evita operaciones innecesariamente costosas.

Sensibilidad a las claves

Procura diferenciar claves distintas, incluso cuando sean parecidas.

Aprovechamiento de capacidad

Busca utilizar apropiadamente las posiciones de la tabla.

Reducción de colisiones

Disminuye la frecuencia con que diferentes claves coinciden en un índice.

Ejemplo de una función deficiente

Supongamos que se utiliza una función que siempre devuelve la posición cero, independientemente de la clave.

def hash_deficiente(clave):
    return 0

claves = [12, 25, 38, 41]

for clave in claves:
    print(clave, hash_deficiente(clave))

Una función hash adecuada procura reducir las colisiones mediante una distribución equilibrada, aunque no puede garantizar su eliminación completa.

2.4 Métodos básicos de cálculo de índices

Existen diferentes métodos para transformar claves en índices. La elección depende de las características de los datos, la capacidad de almacenamiento y las necesidades de la aplicación.

Método de división

Consiste en obtener el residuo de dividir la clave entre la capacidad de la tabla.

h(k) = k mod m

Donde m representa la capacidad de la tabla.

def hash_division(clave, capacidad):
    return clave % capacidad

print(hash_division(123, 10))
Resultado: 3

Es sencillo y rápido, pero su distribución depende de las claves utilizadas y de la capacidad seleccionada.

Método de multiplicación

Consiste en multiplicar la clave por una constante, obtener la parte fraccionaria y utilizarla para calcular el índice.

h(k) = ⌊m (kA mod 1)⌋
  • k: clave numérica.
  • m: capacidad de la tabla.
  • A: constante entre cero y uno.
  • ⌊ ⌋: parte entera inferior.
def hash_multiplicacion(clave, capacidad):
    A = 0.6180339887

    producto = clave * A
    fraccion = producto - int(producto)

    return int(capacidad * fraccion)


print(hash_multiplicacion(25, 10))
Resultado: 4

El ejemplo utiliza claves enteras no negativas y una constante aproximada. En implementaciones reales deben evaluarse la distribución y la precisión del cálculo.

Método de suma de caracteres

Convierte los caracteres de una clave textual en valores numéricos y suma dichos valores.

def hash_caracteres(texto, capacidad):
    total = 0

    for caracter in texto:
        total += ord(caracter)

    return total % capacidad


print(hash_caracteres("ABC", 10))
Resultado: 8

Es fácil de implementar, pero no considera el orden de los caracteres y puede generar numerosas colisiones.

Método hash polinómico

Incorpora el orden de los caracteres mediante multiplicaciones sucesivas y operaciones de módulo.

h siguiente = (h actual × b + ord(c)) mod m

La base b es una constante, c representa cada carácter y m es la capacidad de la tabla.

def hash_polinomico(texto, capacidad):
    valor = 0
    base = 31

    for caracter in texto:
        valor = (
            valor * base + ord(caracter)
        ) % capacidad

    return valor


print(hash_polinomico("ABC", 10))
print(hash_polinomico("CBA", 10))
Resultado: 
8
6

Este procedimiento considera el orden de los caracteres y puede proporcionar una mejor distribución que la suma simple. Sin embargo, las colisiones siguen siendo posibles.

Comparación de métodos

Método Característica Limitación
División Utiliza el residuo de una división. Depende de las claves y la capacidad.
Multiplicación Utiliza una constante y la parte fraccionaria. Requiere seleccionar una constante adecuada.
Suma de caracteres Suma valores numéricos de caracteres. No distingue permutaciones de caracteres.
Polinómico Incorpora el orden de los caracteres. Depende de la base, capacidad y claves.

2.5 Distribución de claves y factor de carga

La distribución de claves describe cómo se reparten los elementos entre las posiciones disponibles de una tabla hash.

Una distribución equilibrada procura evitar que demasiados elementos se concentren en determinadas posiciones. Para estudiar la relación entre los elementos almacenados y la capacidad de la tabla se utiliza el factor de carga (load factor).

Concepto de factor de carga

Es la relación entre la cantidad de elementos almacenados y el número de posiciones disponibles.

α = n / m
  • α: factor de carga.
  • n: cantidad de elementos almacenados.
  • m: capacidad de la tabla.

Ejemplo de cálculo

Supongamos una tabla con diez posiciones y seis elementos almacenados.

α = 6 / 10 = 0.6

Representación simplificada sin colisiones. En encadenamiento separado pueden almacenarse varios elementos en una misma posición.

Interpretación del factor de carga

Factor de carga Interpretación general
0.25 Pocos elementos respecto a la capacidad.
0.50 Ocupación moderada.
0.75 Mayor utilización de la capacidad.
0.90 Ocupación elevada en direccionamiento abierto.
1.00 Un elemento por posición en promedio.
Consideración importante

En el encadenamiento separado, el factor de carga puede superar 1.0, ya que una posición puede contener varios elementos. En direccionamiento abierto convencional, no puede exceder 1.0.

Cálculo en Python

def factor_carga(elementos, capacidad):
    if capacidad <= 0:
        raise ValueError("Capacidad inválida")

    return elementos / capacidad


cantidad = 6
capacidad = 10

resultado = factor_carga(cantidad, capacidad)

print("Factor de carga:", resultado)
Resultado: 
Factor de carga: 0.6

Redimensionamiento de una tabla hash

Cuando una tabla alcanza una ocupación elevada, algunas implementaciones aumentan su capacidad y redistribuyen los elementos.

Este proceso se conoce como redimensionamiento (resizing). La redistribución de las entradas implica recalcular sus ubicaciones, operación conocida como rehashing.

Capacidad inicial
10

8 elementos

α = 0.8

→
Nueva capacidad
20

8 elementos

α = 0.4

  1. La tabla dispone inicialmente de diez posiciones.
  2. Se almacenan ocho elementos y el factor de carga alcanza 0.8.
  3. La implementación decide ampliar la capacidad a veinte posiciones.
  4. Se redistribuyen los ocho elementos.
  5. El nuevo factor de carga es 0.4.

El redimensionamiento consume recursos durante su ejecución, pero puede ayudar a mantener un rendimiento eficiente en las operaciones posteriores.

Ejemplo integrador en Python

El siguiente programa permite calcular índices para un conjunto de claves textuales, identificar coincidencias y determinar el factor de carga de una tabla.

Distribución de claves mediante una función hash polinómica

def funcion_hash(texto, capacidad):
    valor = 0
    base = 31

    for caracter in texto:
        valor = (
            valor * base + ord(caracter)
        ) % capacidad

    return valor


capacidad = 10

claves = ["ANA", "LUIS", "MARTA", "JOSE", "PEDRO"]

tabla = [[] for _ in range(capacidad)]

for clave in claves:
    indice = funcion_hash(clave, capacidad)
    tabla[indice].append(clave)

    print(f"{clave} -> Índice {indice}")

print("\nDistribución de la tabla:")

for indice, elementos in enumerate(tabla):
    print(f"Posición {indice}: {elementos}")

factor = len(claves) / capacidad

print("\nFactor de carga:", factor)

Síntesis

Las funciones hash permiten transformar claves en valores numéricos utilizados para determinar posiciones dentro de una tabla hash. Su diseño influye directamente en la distribución de los elementos y en la eficiencia de las operaciones.

Existen diferentes procedimientos para calcular índices, incluyendo los métodos de división, multiplicación, suma de caracteres y hash polinómico. Cada uno presenta características y limitaciones según el tipo de información almacenada.

El factor de carga permite evaluar la relación entre la cantidad de elementos y la capacidad de la tabla. Una gestión adecuada de este indicador, junto con una función hash bien diseñada, contribuye a mantener operaciones eficientes.

Aunque una función hash procure distribuir uniformemente las claves, las colisiones siguen siendo posibles. Por ello, es necesario estudiar los mecanismos de resolución de colisiones, que constituyen el siguiente subtema.
