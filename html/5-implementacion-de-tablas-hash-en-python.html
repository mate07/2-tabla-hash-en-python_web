Implementación de tablas hash en Python

Implementar tablas hash utilizando diccionarios, programación orientada a objetos y listas enlazadas para almacenar, consultar, actualizar y eliminar información de manera eficiente.

Introducción

Las tablas hash permiten almacenar, organizar y recuperar información mediante asociaciones entre claves y valores. Su funcionamiento se basa en funciones hash que determinan las posiciones de almacenamiento y en mecanismos que permiten resolver las colisiones.

En Python, los diccionarios (dict) proporcionan una implementación eficiente de una estructura asociativa basada en tablas hash. Permiten administrar registros mediante instrucciones sencillas, sin necesidad de desarrollar manualmente los mecanismos internos de almacenamiento.

Sin embargo, comprender cómo construir una tabla hash desde cero resulta fundamental para conocer el funcionamiento de las estructuras de datos, la programación orientada a objetos y los mecanismos de resolución de colisiones.

En este subtema se abordará el uso de diccionarios, la creación de una clase HashTable, el desarrollo de sus operaciones fundamentales y la implementación de colisiones mediante listas enlazadas.

5.1 Uso de diccionarios (dict) como tablas hash

Un diccionario en Python es una estructura de datos que almacena elementos mediante pares clave-valor. Internamente, utiliza una implementación basada en tablas hash para facilitar la localización de registros.

A diferencia de una lista, donde los elementos se consultan mediante índices numéricos, un diccionario permite utilizar claves como cadenas, números y otros objetos hashables.

Características de los diccionarios

Claves únicas

Cada clave identifica una única entrada dentro del diccionario.

Acceso eficiente

Permite recuperar valores mediante claves con una complejidad promedio O(1).

Valores flexibles

Admite cadenas, números, listas, diccionarios y otros objetos.

Estructura dinámica

Permite incorporar y eliminar registros durante la ejecución.

Creación de un diccionario

productos = {
    "P001": "Teclado",
    "P002": "Mouse",
    "P003": "Monitor"
}

print(productos)
Resultado: 
{'P001': 'Teclado', 'P002': 'Mouse', 'P003': 'Monitor'}

Cada código identifica un producto almacenado.

Consulta de elementos

print(productos["P002"])
Resultado: 
Mouse

Los diccionarios permiten recuperar información sin conocer la posición física donde se encuentra almacenada.

Uso de hash() en Python

Python proporciona la función hash() para obtener el valor hash de objetos compatibles.

clave = "P001"

print(hash(clave))
Consideración importante

La función hash() devuelve un número entero que puede ser positivo o negativo. Para las cadenas de texto, este valor puede cambiar entre ejecuciones del intérprete debido a la aleatorización del hash.

Los diccionarios administran automáticamente las colisiones, la distribución de claves y el crecimiento de la estructura.

5.2 Creación y manipulación de pares clave-valor

Los diccionarios permiten realizar operaciones de inserción, búsqueda, actualización, eliminación y recorrido de registros utilizando instrucciones integradas en Python.

Inserción de elementos

Se utiliza una clave para incorporar un nuevo registro.

inventario = {}

inventario["P001"] = 15
inventario["P002"] = 30
inventario["P003"] = 8

print(inventario)
Resultado: 
{'P001': 15, 'P002': 30, 'P003': 8}

Búsqueda de elementos

El método get() permite consultar valores mediante sus claves.

cantidad = inventario.get("P002")

print("Cantidad:", cantidad)
Resultado: 
Cantidad: 30

Cuando la clave no existe, get() devuelve None, salvo que se indique un valor predeterminado.

Actualización de elementos

La asignación de un nuevo valor permite modificar una clave existente.

inventario["P001"] = 20

print(inventario["P001"])
Resultado: 
20

Eliminación de elementos

El método pop() elimina un registro y devuelve su valor.

eliminado = inventario.pop("P003")

print("Eliminado:", eliminado)
print(inventario)
Resultado: 
Eliminado: 8
{'P001': 20, 'P002': 30}

Recorrido de elementos

El método items() permite obtener las claves y sus valores asociados.

for codigo, cantidad in inventario.items():
    print(codigo, cantidad)
Resultado: 
P001 20
P002 30

Métodos frecuentes de los diccionarios

Método u operación Descripción
diccionario[clave] = valor Inserta o reemplaza una entrada.
diccionario[clave] Obtiene un valor; genera KeyError si la clave no existe.
get(clave) Consulta una clave sin generar KeyError por ausencia.
pop(clave) Elimina una entrada y devuelve su valor.
keys() Obtiene una vista de las claves.
values() Obtiene una vista de los valores.
items() Obtiene una vista de los pares clave-valor.
clear() Elimina todos los elementos del diccionario.

5.3 Implementación de una clase HashTable

Aunque los diccionarios permiten trabajar directamente con tablas hash, desarrollar una implementación propia ayuda a comprender su organización interna.

Para ello, se utilizará la programación orientada a objetos (POO) mediante una clase denominada HashTable.

Una clase permite agrupar los atributos y métodos necesarios para administrar los elementos de una tabla hash, facilitando su organización, reutilización y mantenimiento.

Componentes de la clase

Componente Función
HashTable Representa la estructura de datos.
capacity Define la cantidad de posiciones disponibles.
count Registra la cantidad de elementos almacenados.
buckets Contiene las posiciones de almacenamiento.
_hash() Calcula el índice correspondiente a una clave.

En esta primera implementación se utilizarán claves enteras y listas para almacenar los registros que coincidan en un mismo índice.

Creación de la clase

class HashTable:
    def __init__(self, capacity):
        if capacity <= 0:
            raise ValueError("Capacidad inválida")

        self.capacity = capacity
        self.count = 0
        self.buckets = [
            [] for _ in range(capacity)
        ]

    def _hash(self, key):
        return key % self.capacity

Explicación del código

Constructor __init__()

Se ejecuta cuando se crea un objeto e inicializa sus atributos.

Atributo capacity

Define la cantidad de posiciones disponibles.

Atributo count

Registra la cantidad de elementos almacenados.

Atributo buckets

Contiene una lista por cada posición de almacenamiento.

Método _hash()

Calcula el índice utilizando el operador módulo.

Representación conceptual

Objeto HashTable

capacity = 5 | count = 0

0
[ ]
1
[ ]
2
[ ]
3
[ ]
4
[ ]

Inicialmente, todas las posiciones contienen listas vacías.

Creación de un objeto

tabla = HashTable(5)

print(tabla.capacity)
print(tabla.count)
print(tabla.buckets)
Resultado: 
5
0
[[], [], [], [], []]

El objeto dispone de cinco posiciones y no contiene registros almacenados.

5.4 Desarrollo de métodos de inserción, búsqueda y eliminación

Una vez definida la clase, es necesario incorporar los métodos que permiten administrar los registros: inserción, búsqueda, actualización, eliminación y visualización.

Nota de implementación: los siguientes métodos se incorporan dentro de la clase HashTable presentada en el apartado anterior, respetando la indentación correspondiente.

Método de inserción insert()

Recibe una clave y un valor, calcula el índice y almacena el registro cuando la clave no existe.

def insert(self, key, value):
    index = self._hash(key)

    for record in self.buckets[index]:
        if record[0] == key:
            return False

    self.buckets[index].append([key, value])
    self.count += 1

    return True
  1. Calcula el índice mediante _hash().
  2. Revisa los registros almacenados en la posición.
  3. Verifica que la clave no exista.
  4. Agrega el nuevo par clave-valor.
  5. Incrementa el contador.
  6. Devuelve True cuando se realiza la inserción.

Método de búsqueda search()

Permite recuperar el valor asociado a una clave.

def search(self, key):
    index = self._hash(key)

    for record in self.buckets[index]:
        if record[0] == key:
            return record[1]

    return None

El método localiza la posición y revisa sus registros. Devuelve el valor si encuentra la clave y None en caso contrario.

Método de actualización update()

Modifica el valor de una clave previamente almacenada.

def update(self, key, new_value):
    index = self._hash(key)

    for record in self.buckets[index]:
        if record[0] == key:
            record[1] = new_value
            return True

    return False

Conserva la clave original y modifica únicamente el valor asociado.

Método de eliminación delete()

Retira un registro mediante su clave y actualiza el contador.

def delete(self, key):
    index = self._hash(key)

    for position, record in enumerate(
        self.buckets[index]
    ):
        if record[0] == key:
            self.buckets[index].pop(position)
            self.count -= 1
            return True

    return False

Cuando se encuentra la clave, se elimina el registro y se disminuye la cantidad de elementos almacenados.

Métodos auxiliares

Permiten consultar el tamaño, verificar si la estructura está vacía y mostrar su contenido.

def size(self):
    return self.count


def is_empty(self):
    return self.count == 0


def display(self):
    for index, records in enumerate(self.buckets):
        print(f"{index}: {records}")

Resumen de métodos

Método Función Resultado
insert(key, value) Inserta una clave nueva. True o False
search(key) Recupera el valor asociado. Valor o None
update(key, value) Modifica un registro existente. True o False
delete(key) Elimina un registro. True o False
size() Consulta la cantidad de registros. Número entero
is_empty() Comprueba si está vacía. Booleano
display() Muestra la distribución. Salida en consola

5.5 Manejo de colisiones mediante listas enlazadas

El encadenamiento separado permite resolver colisiones almacenando varios elementos en una misma posición.

En los ejemplos anteriores, cada posición contenía una lista de Python. Sin embargo, también es posible implementar el encadenamiento mediante listas enlazadas (linked lists).

Una lista enlazada está formada por nodos. Cada nodo almacena información y una referencia al siguiente elemento de la secuencia.

Estructura de un nodo

Cada nodo de la tabla hash tendrá tres atributos:

key

Identificador del registro.

value

Información asociada con la clave.

next

Referencia al siguiente nodo de la lista.

Creación de la clase HashNode

class HashNode:
    def __init__(self, key, value, next=None):
        self.key = key
        self.value = value
        self.next = next

El atributo next permite establecer cadenas de nodos que comparten una misma posición de la tabla.

Representación conceptual del encadenamiento

Índice 5
Inicio
→
Nodo 15
→
Nodo 25
→
Nodo 35
→ None

Las claves 15, 25 y 35 comparten el índice 5 y se conectan mediante referencias al siguiente nodo.

Tabla hash con listas enlazadas

En lugar de almacenar listas dentro de cada posición, se almacena una referencia al primer nodo.

class HashTable:
    def __init__(self, capacity):
        if capacity <= 0:
            raise ValueError("Capacidad inválida")

        self.capacity = capacity
        self.count = 0
        self.buckets = [None] * capacity

    def _hash(self, key):
        return key % self.capacity

Inicialmente, las posiciones contienen None, porque no existe ningún nodo asociado.

Nota: los siguientes métodos se integran dentro de esta nueva versión de HashTable, que utiliza nodos enlazados en lugar de listas internas.

Inserción mediante nodos

def insert(self, key, value):
    index = self._hash(key)

    current = self.buckets[index]

    while current is not None:
        if current.key == key:
            current.value = value
            return False

        current = current.next

    new_node = HashNode(
        key,
        value,
        self.buckets[index]
    )

    self.buckets[index] = new_node
    self.count += 1

    return True

El procedimiento recorre la cadena y comprueba si la clave existe. Si no existe, crea un nodo y lo incorpora al inicio de la lista enlazada. Si existe, actualiza su valor sin crear otro nodo.

Búsqueda mediante nodos

def search(self, key):
    index = self._hash(key)

    current = self.buckets[index]

    while current is not None:
        if current.key == key:
            return current.value

        current = current.next

    return None

La función recorre la cadena hasta encontrar la clave solicitada o llegar al final.

Eliminación mediante nodos

def delete(self, key):
    index = self._hash(key)

    current = self.buckets[index]
    previous = None

    while current is not None:
        if current.key == key:

            if previous is None:
                self.buckets[index] = current.next
            else:
                previous.next = current.next

            self.count -= 1
            return True

        previous = current
        current = current.next

    return False
Primer nodo

La posición de la tabla debe apuntar al siguiente nodo.

Nodo intermedio o final

El nodo anterior actualiza su referencia para omitir el nodo eliminado.

5.6 Ejemplo completo de funcionamiento en Python

El siguiente programa integra una tabla hash implementada mediante programación orientada a objetos y listas enlazadas para resolver colisiones.

Se utilizarán claves enteras que representan códigos de productos. El ejemplo incorpora las operaciones de inserción, búsqueda, actualización, eliminación, consulta de tamaño y visualización.

Implementación completa de HashTable y HashNode

class HashNode:
    def __init__(self, key, value, next=None):
        self.key = key
        self.value = value
        self.next = next


class HashTable:
    def __init__(self, capacity):
        if capacity <= 0:
            raise ValueError("Capacidad inválida")

        self.capacity = capacity
        self.count = 0
        self.buckets = [None] * capacity

    def _hash(self, key):
        return key % self.capacity

    def insert(self, key, value):
        index = self._hash(key)
        current = self.buckets[index]

        while current is not None:
            if current.key == key:
                current.value = value
                return False

            current = current.next

        new_node = HashNode(
            key,
            value,
            self.buckets[index]
        )

        self.buckets[index] = new_node
        self.count += 1

        return True

    def search(self, key):
        index = self._hash(key)
        current = self.buckets[index]

        while current is not None:
            if current.key == key:
                return current.value

            current = current.next

        return None

    def update(self, key, value):
        index = self._hash(key)
        current = self.buckets[index]

        while current is not None:
            if current.key == key:
                current.value = value
                return True

            current = current.next

        return False

    def delete(self, key):
        index = self._hash(key)

        current = self.buckets[index]
        previous = None

        while current is not None:
            if current.key == key:

                if previous is None:
                    self.buckets[index] = current.next
                else:
                    previous.next = current.next

                self.count -= 1
                return True

            previous = current
            current = current.next

        return False

    def size(self):
        return self.count

    def is_empty(self):
        return self.count == 0

    def display(self):
        for index in range(self.capacity):
            current = self.buckets[index]
            elements = []

            while current is not None:
                elements.append(
                    f"{current.key}:{current.value}"
                )
                current = current.next

            print(f"{index}: {elements}")


# Crear tabla hash
products = HashTable(10)

# Insertar productos
products.insert(15, "Teclado")
products.insert(25, "Mouse")
products.insert(35, "Monitor")
products.insert(12, "Impresora")

# Buscar producto
print("Búsqueda:", products.search(25))

# Actualizar producto
products.update(25, "Mouse inalámbrico")
print("Actualizado:", products.search(25))

# Eliminar producto
products.delete(15)

# Consultar tamaño
print("Cantidad:", products.size())

# Mostrar tabla
print("\nTabla final:")
products.display()

Síntesis

Python proporciona los diccionarios dict como estructuras asociativas eficientes que permiten almacenar información mediante pares clave-valor. Sus operaciones integradas facilitan la inserción, búsqueda, actualización y eliminación de registros.

La implementación manual de una tabla hash mediante una clase HashTable permite comprender cómo se organizan los elementos, cómo se calculan los índices y cómo se administran las colisiones.

El uso de listas enlazadas mediante nodos HashNode proporciona un mecanismo de encadenamiento separado que conserva diferentes registros asociados con una misma posición.

La programación orientada a objetos facilita organizar estas operaciones en métodos reutilizables y mantener el control del estado de la estructura.

Comprender los diccionarios integrados y las implementaciones propias permite seleccionar soluciones adecuadas según las necesidades de una aplicación y constituye la base para desarrollar sistemas de búsqueda, inventarios, catálogos y otros programas que requieren acceso eficiente a la información.
