Operaciones fundamentales de una tabla hash

Comprender e implementar las operaciones de inserción, búsqueda, actualización y eliminación de registros, analizando su funcionamiento y eficiencia en Python.

Introducción

Las tablas hash son estructuras de datos que permiten almacenar y recuperar información mediante asociaciones entre claves y valores. Su eficiencia depende del uso de funciones hash y de mecanismos adecuados para resolver las colisiones.

Una vez comprendido cómo se calculan los índices y cómo se gestionan las colisiones, es necesario estudiar las operaciones que permiten administrar los elementos almacenados.

Las operaciones fundamentales de una tabla hash son la inserción, búsqueda, actualización y eliminación de registros. Estas permiten incorporar nueva información, recuperar valores mediante claves, modificar registros existentes y retirar aquellos que ya no son necesarios.

En Python, estas operaciones pueden realizarse utilizando diccionarios dict o mediante implementaciones propias de tablas hash. Su aplicación resulta especialmente útil en inventarios, registros académicos, catálogos de productos y sistemas de gestión de usuarios.

Eliminación

4.1 Inserción de elementos mediante claves

La inserción (insert) consiste en incorporar un nuevo elemento dentro de una tabla hash, estableciendo una asociación entre una clave y un valor.

Para almacenar el elemento, se calcula el índice correspondiente mediante una función hash y se determina la ubicación donde debe guardarse.

Proceso de inserción

  1. Se recibe una clave y su valor asociado.
  2. Se aplica la función hash para determinar el índice.
  3. Se consulta la posición correspondiente.
  4. Se verifica si la clave ya existe.
  5. Si la clave no existe, se incorpora el registro utilizando el mecanismo de resolución de colisiones correspondiente.

Inserción mediante diccionarios en Python

Los diccionarios permiten insertar registros mediante la asignación de una clave y un valor:

diccionario[clave] = valor

Ejemplo:

productos = {}

productos["P001"] = "Teclado"
productos["P002"] = "Mouse"
productos["P003"] = "Monitor"

print(productos)
Resultado: 
{'P001': 'Teclado', 'P002': 'Mouse', 'P003': 'Monitor'}

El diccionario almacena cada producto utilizando su código como clave, sin necesidad de calcular manualmente los índices.

Inserción utilizando una función hash propia

Para comprender el funcionamiento interno, puede utilizarse una tabla hash con encadenamiento separado.

capacidad = 10
tabla = [[] for _ in range(capacidad)]


def insertar(clave, valor):
    indice = clave % capacidad

    for registro in tabla[indice]:
        if registro[0] == clave:
            return False

    tabla[indice].append([clave, valor])
    return True


insertar(15, "Teclado")
insertar(25, "Mouse")
insertar(35, "Monitor")

print(tabla[5])
Resultado: 
[[15, 'Teclado'], [25, 'Mouse'], [35, 'Monitor']]
Observación

Las claves 15, 25 y 35 producen el mismo índice, pero el encadenamiento separado permite conservar los tres registros. La función devuelve True si incorpora un elemento nuevo y False si la clave ya existe.

4.2 Búsqueda y recuperación de valores

La búsqueda (search) consiste en localizar un elemento almacenado utilizando su clave de identificación.

Es una de las operaciones más importantes de las tablas hash, ya que permite recuperar información sin realizar necesariamente una búsqueda secuencial sobre toda la estructura.

Proceso de búsqueda

  1. Se recibe la clave que se desea localizar.
  2. Se aplica la función hash.
  3. Se obtiene el índice correspondiente.
  4. Se revisa la posición calculada.
  5. Si existe una colisión, se utiliza el mecanismo correspondiente para localizar la clave.
  6. Se devuelve el valor asociado o se informa que el registro no existe.

Búsqueda con diccionarios en Python

productos = {
    "P001": "Teclado",
    "P002": "Mouse",
    "P003": "Monitor"
}

print(productos["P002"])
Resultado: 
Mouse

Cuando se utiliza una clave inexistente mediante corchetes, Python genera una excepción KeyError.

print(productos["P005"])
Error esperado

Se produce una excepción KeyError porque la clave P005 no se encuentra registrada.

Uso del método get()

El método get() permite realizar búsquedas sin generar una excepción cuando la clave no existe.

producto = productos.get("P005")

print(producto)
Resultado: 
None

También permite establecer un valor predeterminado:

producto = productos.get(
    "P005",
    "Producto no encontrado"
)

print(producto)
Resultado: 
Producto no encontrado

Búsqueda en una tabla hash implementada manualmente

Continuando con la tabla creada en el apartado anterior, se puede implementar una función de búsqueda.

def buscar(clave):
    indice = clave % capacidad

    for registro in tabla[indice]:
        if registro[0] == clave:
            return registro[1]

    return None


print(buscar(25))
print(buscar(45))
Resultado: 
Mouse
None

Consideración: devolver None para indicar una búsqueda fallida es válido en este ejemplo. Sin embargo, cuando None puede almacenarse como valor legítimo, conviene utilizar un marcador especial o devolver información adicional.

4.3 Actualización de valores existentes

La actualización (update) consiste en modificar el valor asociado con una clave previamente almacenada.

Esta operación es útil cuando la información de un registro cambia, pero su identificador debe mantenerse. Por ejemplo, un sistema de inventario puede actualizar la cantidad disponible de un producto sin modificar su código.

Proceso de actualización

  1. Se recibe la clave del registro.
  2. Se calcula el índice correspondiente.
  3. Se localiza la clave dentro de la tabla.
  4. Si existe, se reemplaza o modifica su valor.
  5. Si no existe, se informa que la actualización no pudo realizarse.

→

Actualización mediante diccionarios

inventario = {
    "P001": 15,
    "P002": 30,
    "P003": 8
}

inventario["P001"] = 20

print(inventario)
Resultado: 
{'P001': 20, 'P002': 30, 'P003': 8}

El valor asociado con P001 cambia de 15 a 20. Sin embargo, una asignación directa también puede insertar una clave nueva cuando esta no existe.

Actualización controlada

Para modificar únicamente registros existentes, debe comprobarse previamente la clave.

def actualizar_producto(codigo, cantidad):
    if codigo in inventario:
        inventario[codigo] = cantidad
        return True

    return False


print(actualizar_producto("P002", 35))
print(actualizar_producto("P005", 10))
Resultado: 
True
False

La primera operación modifica un producto existente. La segunda no realiza cambios porque la clave no está registrada.

Actualización en una tabla hash manual

Continuando con la tabla hash de encadenamiento separado creada en el apartado 4.1:

def actualizar(clave, nuevo_valor):
    indice = clave % capacidad

    for registro in tabla[indice]:
        if registro[0] == clave:
            registro[1] = nuevo_valor
            return True

    return False


actualizar(25, "Mouse inalámbrico")

print(buscar(25))
Resultado: 
Mouse inalámbrico

El procedimiento localiza la clave dentro de la lista correspondiente y reemplaza su valor, sin modificar el índice ni eliminar el registro.

4.4 Eliminación de elementos

La eliminación (delete) consiste en retirar un registro de una tabla hash utilizando su clave de identificación.

Esta operación es necesaria cuando un elemento deja de formar parte del conjunto de información administrado, como un producto descontinuado, un usuario retirado o un registro cancelado.

Proceso de eliminación

  1. Se recibe la clave que se desea eliminar.
  2. Se calcula el índice mediante la función hash.
  3. Se localiza el registro correspondiente.
  4. Se verifica que la clave exista.
  5. Se elimina el elemento utilizando el mecanismo correspondiente.
  6. Se informa si la operación se completó correctamente.

Eliminación con diccionarios

Python proporciona diferentes mecanismos para eliminar entradas de un diccionario.

Uso de del

La instrucción del elimina directamente una entrada utilizando su clave.

productos = {
    "P001": "Teclado",
    "P002": "Mouse",
    "P003": "Monitor"
}

del productos["P002"]

print(productos)
Resultado: 
{'P001': 'Teclado', 'P003': 'Monitor'}

Si se intenta eliminar una clave inexistente mediante del, Python genera una excepción KeyError.

Uso del método pop()

El método pop() elimina una entrada y devuelve el valor asociado.

producto = productos.pop(
    "P003",
    "No encontrado"
)

print(producto)
print(productos)
Resultado: 
Monitor
{'P001': 'Teclado'}

El segundo argumento permite establecer un valor predeterminado cuando la clave no existe.

Eliminación en una tabla hash manual

Continuando con la tabla hash implementada mediante encadenamiento separado:

def eliminar(clave):
    indice = clave % capacidad

    for posicion, registro in enumerate(tabla[indice]):
        if registro[0] == clave:
            tabla[indice].pop(posicion)
            return True

    return False


print(eliminar(25))
print(buscar(25))
print(tabla[5])
Resultado: 
True
None
[[15, 'Teclado'], [35, 'Monitor']]

El registro asociado con la clave 25 se elimina de la lista correspondiente, sin afectar los otros elementos almacenados en el mismo índice.

Eliminación y resolución de colisiones

La eliminación depende del método utilizado para resolver las colisiones.

Método Forma de eliminación
Encadenamiento separado Se retira el elemento de la lista o cadena correspondiente.
Exploración lineal Puede utilizar marcadores de eliminación o reorganizar elementos siguiendo reglas específicas.
Exploración cuadrática Generalmente requiere preservar las secuencias de búsqueda mediante marcadores.
Doble hashing Debe conservar la continuidad de la exploración para localizar registros posteriores.
Marcadores de eliminación (tombstones)

En direccionamiento abierto, marcar una posición eliminada como si nunca hubiera sido utilizada puede interrumpir las búsquedas. Los marcadores de eliminación permiten conservar la continuidad de la secuencia de exploración.

4.5 Análisis de eficiencia de las operaciones

La eficiencia de una tabla hash se evalúa considerando el tiempo necesario para insertar, buscar, actualizar y eliminar elementos.

Bajo condiciones adecuadas, las operaciones fundamentales de una tabla hash presentan una complejidad temporal promedio de O(1), conocida como tiempo constante.

Esto significa que el tiempo de acceso esperado no aumenta proporcionalmente con la cantidad de elementos almacenados, siempre que exista una distribución adecuada de las claves y se mantenga controlado el factor de carga.

Complejidad temporal

Operación Caso promedio Peor caso
Inserción O(1) O(n)
Búsqueda O(1) O(n)
Actualización O(1) O(n)
Eliminación O(1) O(n)

Estas complejidades corresponden al análisis habitual de tablas hash con claves de tamaño acotado y distribución adecuada.

En encadenamiento separado, el peor caso puede producirse cuando numerosas claves terminan en una misma posición. En direccionamiento abierto, un factor de carga elevado puede requerir explorar múltiples posiciones.

Factores que afectan el rendimiento

Calidad de la función hash

Determina qué tan uniformemente se distribuyen las claves.

Factor de carga

Relaciona la cantidad de elementos con la capacidad de almacenamiento.

Resolución de colisiones

Define las operaciones adicionales necesarias cuando dos claves coinciden.

Redimensionamiento

Permite ampliar la capacidad para mantener un rendimiento adecuado.

Tipo de claves

Influye en el costo de calcular valores hash y comparar identificadores.

Frecuencia de operaciones

Determina la importancia de inserciones, búsquedas y eliminaciones.

Comparación con búsquedas en listas

En una lista no ordenada, localizar un valor puede requerir recorrer los elementos hasta encontrarlo.

Búsqueda secuencial con una lista

numeros = [10, 20, 30, 40, 50]

buscado = 40

for numero in numeros:
    if numero == buscado:
        print("Encontrado")
        break
Resultado: Encontrado

La búsqueda puede necesitar revisar varios elementos. Su complejidad en el peor caso es O(n).

Búsqueda mediante una tabla hash

datos = {
    10: "A",
    20: "B",
    30: "C",
    40: "D",
    50: "E"
}

print(datos[40])
Resultado: D

El diccionario permite acceder directamente al valor mediante su clave, con una complejidad O(1) promedio.

Importante: los diccionarios no son superiores para todas las operaciones. Las listas siguen siendo apropiadas cuando se necesita conservar una secuencia y acceder a los elementos mediante posiciones numéricas.

Ejemplo integrador en Python

El siguiente programa implementa una tabla hash mediante encadenamiento separado que permite insertar, buscar, actualizar y eliminar registros.

Se utilizan claves enteras y listas para administrar los elementos que generan colisiones.

Implementación completa de una tabla hash

class TablaHash:
    def __init__(self, capacidad):
        if capacidad <= 0:
            raise ValueError("La capacidad debe ser positiva")

        self.capacidad = capacidad
        self.tabla = [
            [] for _ in range(capacidad)
        ]

    def hash(self, clave):
        return clave % self.capacidad

    def insertar(self, clave, valor):
        indice = self.hash(clave)

        for registro in self.tabla[indice]:
            if registro[0] == clave:
                return False

        self.tabla[indice].append([clave, valor])
        return True

    def buscar(self, clave):
        indice = self.hash(clave)

        for registro in self.tabla[indice]:
            if registro[0] == clave:
                return registro[1]

        return None

    def actualizar(self, clave, nuevo_valor):
        indice = self.hash(clave)

        for registro in self.tabla[indice]:
            if registro[0] == clave:
                registro[1] = nuevo_valor
                return True

        return False

    def eliminar(self, clave):
        indice = self.hash(clave)

        for posicion, registro in enumerate(
            self.tabla[indice]
        ):
            if registro[0] == clave:
                self.tabla[indice].pop(posicion)
                return True

        return False

    def mostrar(self):
        for indice, registros in enumerate(self.tabla):
            print(f"{indice}: {registros}")


# Crear tabla hash
productos = TablaHash(10)

# Insertar productos
productos.insertar(15, "Teclado")
productos.insertar(25, "Mouse")
productos.insertar(35, "Monitor")
productos.insertar(12, "Impresora")

# Buscar
print("Búsqueda:", productos.buscar(25))

# Actualizar
productos.actualizar(25, "Mouse inalámbrico")
print("Actualizado:", productos.buscar(25))

# Eliminar
productos.eliminar(15)

# Mostrar tabla final
print("\nTabla final:")
productos.mostrar()

Análisis del ejemplo

Estructura

La clase TablaHash utiliza listas asociadas a índices para organizar los registros.

Inserción

El método insertar() agrega registros y evita incorporar claves duplicadas.

Búsqueda

El método buscar() recupera el valor asociado con una clave.

Actualización

El método actualizar() modifica un valor sin cambiar su identificador.

El método eliminar() retira el registro solicitado sin afectar los demás elementos.

Resolución de colisiones

Aplicación práctica: esta implementación demuestra cómo administrar registros mediante claves únicas, resolver colisiones y ejecutar operaciones fundamentales dentro de una misma estructura de datos.

Síntesis

Las operaciones fundamentales de una tabla hash permiten administrar los elementos almacenados mediante claves únicas.

La inserción incorpora nuevos registros, la búsqueda recupera valores, la actualización modifica información existente y la eliminación retira los elementos que ya no se necesitan.

En Python, los diccionarios dict facilitan estas operaciones mediante una sintaxis directa. También es posible implementar tablas hash manualmente para comprender su funcionamiento interno y controlar la resolución de colisiones.

La eficiencia promedio de estas operaciones es O(1), siempre que exista una distribución adecuada de claves y se mantenga controlado el factor de carga.

El dominio de estas operaciones constituye la base para desarrollar implementaciones de tablas hash mediante clases en Python y aplicarlas en sistemas informáticos que requieren almacenamiento y recuperación eficiente de información.
